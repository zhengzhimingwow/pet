# 武器效果

新联机战斗使用第 6 版规则。每次出手从已拥有的武器里随机抽一把，本场抽到即移出武器池。

| 武器 | 专属效果 |
| --- | --- |
| 平底锅 | 手麻 · 命中后，对手下一次命中的伤害降低 25%。 |
| 青龙偃月刀 | 斩杀 · 命中生命低于 30% 的对手时，伤害提高 35%。 |
| 轩辕剑 | 破甲 · 命中时无视对手一半防御。 |
| 玩具锤 | 碎盾 · 命中时击碎护盾，本次攻击不被该护盾减伤。 |
| 棒球棍 | 开场重击 · 对生命至少还有 70% 的对手额外造成 7 点伤害。 |
| 雨伞 | 护盾 · 命中后获得一层护盾，抵挡下一次命中的最多 12 点伤害。 |
| 扫帚 | 露出破绽 · 命中后，己方下次具备连击条件时必定追加连击。 |
| 锅铲 | 翻身 · 命中后清除自身减益，并恢复最多 4 点生命。 |
| 拳击手套 | 补拳 · 主击命中且对手未倒下时，追加一拳，基础伤害 5 点。 |
| 悠悠球 | 专注 · 命中后，下次主击命中的暴击率提高 20 个百分点。 |
| 回旋镖 | 折返 · 首击被闪避时，折返追击，基础伤害 5 点。 |
| 雪球 | 冰冷 · 命中后，对手下一次主击命中无法暴击。 |
| 水枪 | 浸湿 · 命中后，对手下一次受击的计算伤害增加 5 点。 |
| 折扇 | 借风 · 命中后，下次被主击时的闪避率提高 18 个百分点。 |
| 拖鞋 | 精准 · 使对手对本次攻击的闪避率降低 12 个百分点。 |
| 胡萝卜 | 急救 · 自身生命低于 50% 时，命中后恢复最多 10 点生命。 |
| 咸鱼 | 盐渍 · 命中后，对手接下来两次受击的计算伤害各增加 3 点。 |
| 吉他 | 封招 · 命中后，对手下一次主击命中无法触发连击功法。 |
| 橡皮鸭 | 分心 · 命中后，对手下一次主击被闪避的概率提高 12 个百分点。 |
| 灯笼 | 灯火 · 命中后，接下来两次命中各恢复最多 4 点生命。 |

状态按各自的条件消耗。未触发的状态在本场结束时清除。战报逐回合保留命中、闪避、额外攻击、护盾、减益和回血，回放与跳过共用战斗服保存结果。
