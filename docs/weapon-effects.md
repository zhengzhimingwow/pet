# 武器效果设计

每次出手继续从已拥有的武器中随机抽取，本场抽到即移出池子。效果与武器绑定，玩家收集的是不同打法。数值为首轮试玩建议。

| 武器 | 效果 | 触发 |
| --- | --- | --- |
| 平底锅 | 护住自己，下一次被命中的实际伤害减 4，最低为 1 | 抡击命中后 |
| 青龙偃月刀 | 破防，使目标接下来承受的两次主攻击各多扣 3 点生命 | 劈砍命中后 |
| 轩辕剑 | 本次攻击忽略 50% 的防御，向下取整 | 本次出招 |
| 玩具锤 | 震荡，使目标下一次主攻击少造成 4 点伤害，最低为 1 | 砸击命中后 |
| 棒球棍 | 热身，自己的下一次主攻击伤害加 4 | 挥击命中后 |
| 雨伞 | 格挡，把下一次受到的暴击降为普通命中 | 撑伞命中后 |
| 扫帚 | 扫掉目标身上最早生效的一项增益 | 命中后 |
| 锅铲 | 借力，给自己恢复 5 点生命，上限为最大生命 | 命中后 |
| 拳击手套 | 追加 3 点伤害。战报分开记录两拳，目标倒地后结束 | 第一拳命中后 |
| 悠悠球 | 牵制，使目标下一次攻击的暴击率降低 10 个百分点，最低为 0 | 命中后 |
| 回旋镖 | 折返时追击 4 点，目标倒地后结束 | 第一段命中后 |
| 雪球 | 冰冷，使目标下一次主攻击伤害降低 25%，向下取整，最低为 1 | 命中后 |
| 水枪 | 湿滑，使目标下一次出手的闪避判定概率提高 12 个百分点 | 命中后 |
| 折扇 | 借风，自己的下一次被攻击有额外 12 个百分点的闪避机会 | 命中后 |
| 拖鞋 | 打散准备，使目标下一次命中时无法触发连击功法 | 命中后 |
| 胡萝卜 | 士气，清除自身最早生效的一项减益 | 出手前 |
| 咸鱼 | 脱手再甩，目标第一次闪避后，用同一把咸鱼再判定一次命中 | 第一次攻击被闪避时 |
| 吉他 | 音浪，给自己恢复 3 点生命，并使下一次主攻击伤害加 2 | 命中后 |
| 橡皮鸭 | 弹跳，目标本次闪避时仍会受到 2 点擦伤 | 被闪避时 |
| 灯笼 | 照亮，自己的下一次主攻击使目标闪避率降低 10 个百分点 | 命中后 |

首批建议先试平底锅、青龙偃月刀、雪球、锅铲和扫帚，分别验证护盾、破防、减伤、治疗和驱散。效果依附于现有出招顺序，双方仍轮流出手。

持续状态按触发条件消耗，最多保留到接下来两次持有者出手结束。同名状态刷新次数，数值独立的状态可同时存在。后续接入战报时，分别记下施加、抵消的伤害或治疗量和移除原因，沿用开战快照和保存的事件回放。
